## Package Overview

**ggFishPlots** is a CRAN-targeted R package that visualises and calculates fisheries life history parameters (growth, length-weight relationships, maturity ogives, catch curves) from raw biological survey data. All plots are ggplot2 objects. Calculations use tidyverse packages and `fishmethods`.

## Development Commands

```r
# Regenerate NAMESPACE and man/ from roxygen2 comments
devtools::document()

# Full CRAN-style check (run before any release)
devtools::check()

# Quick check without rebuilding vignettes
devtools::check(vignettes = FALSE)

# Install locally for testing
devtools::install()

# Run a single example interactively
data(survey_ghl)
plot_growth(survey_ghl, length = "length", age = "age")

# Load package without installing (faster iteration)
devtools::load_all()
```

Tests live in `tests/testthat/` (run with `devtools::test()`); `@examples` blocks are also exercised by `devtools::check()`.

## Architecture

### Consistent return contract

Every exported plot function returns a **named list** with three elements:

| Element | Type | Purpose |
|---------|------|---------|
| `plot` | `ggplot` | The ggplot2 object |
| `text` | `character` | Plain-text summary for embedding in Rmarkdown/Shiny |
| `params` | `data.frame` / `tibble` | Estimated model parameters |

`plot_growth` additionally returns `model` (the raw `fishmethods::growth` object, if `return_model = TRUE`) and `data` (the prepared data, if `return_data = TRUE`).

### Shared parameter conventions

All main functions share these parameters (documented via `@inheritParams plot_maturity`):
- `dt` — input data frame (never modified; columns are renamed internally to standard names)
- `sex`, `female.sex`, `male.sex` — sex column name and sex codes (default `"F"` / `"M"`)
- `split.by.sex` — logical; produces a combined plot coloured by sex
- `base_size` — base font size forwarded to `theme_fishplots()`
- `legend.position` — forwarded to `ggplot2::theme()`

Sex colours are hardcoded: females `#FF5F68` (red), males `#449BCF` (blue).

### Column renaming pattern

Each function renames user-supplied column names to canonical internal names (`length`, `age`, `sex`, `maturity`, `weight`) via `dplyr::rename("canonical" = !!user_arg)`. This avoids `[[]]` indexing throughout the body but means **column conflicts must be handled before renaming** — see the guard blocks like `if ("age" %in% colnames(dt) && age != "age") dt <- dplyr::select(dt, -age)`.

### Growth model dispatch

`plot_growth` wraps `fishmethods::growth()` and dispatches by string name (`"vout"` / `"gout"` / `"lout"`) using `eval(parse(text = paste0("laMod$", growth.model)))`. The `compute_L0_row()` helper (defined at the top of `plot_growth.R`, not exported) derives length at age 0 with delta-method standard errors from the fitted model's vcov.

### Utility functions

- `round_any()` — Hadley Wickham's rounding helper (exported, `@keywords internal`)
- `unlogit()` — back-transforms a logit model prediction to the response scale; used by `plot_maturity`
- `theme_fishplots()` — thin wrapper around `theme_classic()` with blank backgrounds
- `zzz.R` — declares global variables via `utils::globalVariables()` to suppress R CMD CHECK notes from bare column names used in dplyr/ggplot2 NSE

### Example dataset

`data(survey_ghl)` — Greenland halibut measurements from IMR surveys. Used in all `@examples` blocks. Columns: `length` (cm), `weight` (kg), `age` (years), `sex` (`"F"`/`"M"`), `maturity` (0/1).

## CRAN / Package Hygiene Notes

- Documentation is generated by **roxygen2** (RoxygenNote 7.3.3). Never edit `man/*.Rd` or `NAMESPACE` by hand.
- `devtools::check()` must produce 0 errors, 0 warnings, 0 notes before a CRAN submission.
- The `@import dplyr ggplot2` directives (whole-namespace imports) are intentional style choices for this package; prefer `@importFrom pkg fun` for any new functions added.
- Debugging parameter blocks (commented-out argument assignments) are intentionally left at the top of each function body to aid interactive development — do not remove them.
